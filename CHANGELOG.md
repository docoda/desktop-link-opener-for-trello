# Changelog

## 1.0.4

- The leftover tab now closes only after you return to Firefox, so Firefox's "choose an application" prompt is no longer dismissed too early
- Shows a hint if the Trello desktop app doesn't respond
- Removed the unneeded "tabs" permission
- Desktop only: dropped Firefox for Android from the manifest

## 1.0.3

- Localized UI: English (default) and German
- Added author and homepage link to the manifest

## 1.0.2

- Initial public release on addons.mozilla.org
- Opens Trello board, card and workspace links in the Trello desktop app
- Closes the leftover tab or returns to the previous page
- "Open in browser instead" link and toolbar toggle
